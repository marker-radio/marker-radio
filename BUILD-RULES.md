
# Marker Radio build rules

These rules are mandatory. If a request conflicts with them, follow this file.

## Scope
- Finish the 50-mile ring around Hicksville first.
- Columbus is outside the ring. Do not work it during ring work.
- One city at a time. Current city stays current until the user types: CITY done
  Example: Hicksville done

## Each city must have all 7 as separate cards
1. Landmarks and historical-society sites
2. How the town formed: rail, river, canal, industry
3. People: born, lived, died, buried
4. Parks and public land
5. Native history
6. War and freedom sites
7. Local legends

## How to add cards
- Before writing anything, the user pastes that city's name list from CITIES.md or from a name: search in data.js.
- If no name list is in the chat, write zero story objects.
- Add only topics that are missing.
- Do not guess.
- Do not twin a site, person, factory, or fact already on the list.
- long stays empty quotes.
- Next means next missing pins for the current city, not the next town.

## Order
1. Hicksville until Hicksville done
2. Then towns in the ring, nearest first
3. After the ring is closed, Ohio by population

## Do not
- Start over and delete data.js
- Open a new city without CITY done
- Invent pins to look busy
